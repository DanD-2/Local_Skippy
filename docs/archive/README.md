# Archive — Workstation-Era Documentation

## Purpose

This directory contains documentation from the original Local_LLM project, when the target was
a mixed creative workstation (Ubuntu Studio) rather than a dedicated headless AI server.

These files are kept for historical reference only.  They do **not** apply to the current
Ubuntu Server deployment model.

## Archived Files

| File                               | Original purpose                                      |
|------------------------------------|-------------------------------------------------------|
| `cad-selection.md`                 | CAD software comparison for the Linux workstation     |
| `creative-app-compatibility.md`    | Resolve, Blender, OBS compatibility analysis          |
| `post-install-workstation-validation.md` | Validation checklist for the mixed workstation  |
| `resolve-nvidia-prep.md`           | NVIDIA driver settings for DaVinci Resolve sharing    |

## When These Would Be Relevant Again

If the project is ever reconfigured as a mixed workstation (which is not the current direction),
these files would serve as a starting point.  However, the GPU and OS strategy would need to be
reviewed from scratch against current hardware and software versions.
